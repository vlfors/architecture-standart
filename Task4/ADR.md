Централизованное обновление ставок в АБС

Сохраняем АБС как единую точку управления ставками для обеспечения согласованности данных
Модуль управления ставками в АБС остается основным источником информации о ставках


Интеграционный слой для распространения данных о ставках

Используем существующий интеграционный слой для распространения информации о ставках
Кэширование данных о ставках в Redis для снижения нагрузки на АБС при частых запросах
Очередь сообщений (RabbitMQ) для уведомления о изменениях ставок


Сервис синхронизации ставок

Новый компонент для обработки обновлений ставок и синхронизации данных между системами
Обновляет кэш и инициирует процесс экспорта файла для партнерского кол-центра


Сервис экспорта файлов

Новый компонент для создания и отправки файлов с актуальными ставками
Формирует файлы в согласованном формате (CSV/Excel)
Взаимодействует с SFTP-сервером для безопасной передачи файлов


SFTP-сервер для обмена файлами

Обеспечивает безопасный механизм передачи файлов партнерскому кол-центру
Поддерживает шифрование и аутентификацию для защиты данных
Позволяет партнерскому кол-центру получать файлы в асинхронном режиме


Интеграция с телефонной системой

Настройка автоматической маршрутизации звонков при перегрузке основного кол-центра

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Опишите здесь наиболее важные альтернативные решения.

Альтернатива 1: Прямой доступ партнерского кол-центра к API

Преимущества: Более быстрое обновление данных, отсутствие необходимости в передаче файлов
Недостатки: Требует существенных доработок на стороне партнерского кол-центра, повышенные требования к безопасности при предоставлении доступа к API внешней организации

Альтернатива 2: Email-рассылка файлов со ставками

Преимущества: Простота реализации, отсутствие необходимости в настройке SFTP-сервера
Недостатки: Меньший уровень автоматизации, риски безопасности при передаче данных по email, сложности с отслеживанием доставки
**Недостатки, ограничения, риски**

Подробно опишите здесь недостатки, ограничения и риски выбранного решения.

Асинхронность обновления: Задержка в обновлении данных в партнерском кол-центре может привести к временной неконсистентности информации
Зависимость от файлового обмена: Процесс обмена файлами менее надежен и оперативен по сравнению с API-интеграцией
Ручные операции: Партнерский кол-центр должен выполнять операции по загрузке данных из файлов в свою систему
Ограничения

Технические ограничения партнерского кол-центра: Невозможность использования API-интеграции ограничивает варианты решения
Частота обновлений: Частые обновления ставок могут создать избыточную нагрузку на процесс обмена файлами
Объем передаваемых данных: Ограничения на размер и формат файлов для обмена данными
